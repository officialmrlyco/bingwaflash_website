The working set

Built for the counter.

Not a camera demo. It covers the full job: capture, review, route, recharge, and keep a clear record of what happened.

01

Camera scanner

Read voucher digits from scratch cards, screenshots, and printed lists. Nothing runs until the result is reviewed.Single / Bulk / Focus box
02

Manual entry

Type one code or paste a group of voucher lines when the camera is not the practical choice.Type / Paste / Edit
03

SIM and carrier

Choose the SIM, match its carrier, and maintain the correct recharge or balance USSD template.SIM selection / Editable codes
04

Balance checks

Run a supported balance request and keep the carrier response visible instead of guessing what happened.USSD / Carrier response
05

Voucher history

Separate saved, attempted, confirmed, and uncertain results so the same voucher is not treated casually.Local record / Clear status
06

Bulk runs

Review a detected list, save overflow safely, and process the chosen vouchers in a controlled sequence.Review first / Ordered execution
